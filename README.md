# 🚀 Getting Started

## Prerequisites

- Java 8+
- IntelliJ IDEA / Eclipse / VS Code

---

## Clone the Repository

```bash
git clone https://github.com/TanuSharma08/java-core-mastery.git
```

```bash
cd java-core-mastery
```

---

## Compile & Run

```bash
javac src/basics/HelloWorld.java
```

```bash
java src/basics/HelloWorld
```
